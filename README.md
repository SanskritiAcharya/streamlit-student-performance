# Student Performance Analytics (Streamlit)

Dashboard for the Query Design & Analysis Streamlit review, using the UCI Student Performance dataset.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app opens at http://localhost:8501.

## Contents

- `app.py` - Streamlit application (Overview, Explore, SQL Query, Predict tabs)
- `data/` - UCI Student Performance dataset (Math and Portuguese)
- `.streamlit/config.toml` - theme settings
- `Streamlit_Review_APA.docx` - APA review
